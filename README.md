# x-post-images

X投稿に添付する画像の配信専用リポジトリです。

画像は `images/` にまとめ、Bufferなどから参照できるGitHub Raw URLで公開します。画像の対応表は [`images.json`](images.json) にあります。

## 運用ルール

- Xに公開して問題ない画像だけを配置します。
- 画像ファイル名は半角英小文字・数字・ハイフンのみを使います。
- 追加時は `images.json` とVault側の画像一覧も同時に更新します。
- 原本は各アプリのリポジトリまたは `_handoff/` に置き、このリポジトリには配信用の縮小版だけを置きます。
