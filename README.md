# x-post-images

X投稿に添付する画像の配信専用リポジトリです。

画像は `images/` にまとめ、Bufferなどから参照できるGitHub Raw URLで公開します。画像の対応表は [`images.json`](images.json) にあります。

## 運用ルール

- Xに公開して問題ない画像だけを配置します。
- 画像ファイル名は半角英小文字・数字・ハイフンのみを使います。
- 追加時は `images.json` とVault側の画像一覧も同時に更新します。
- 原本は各アプリのリポジトリまたは `_handoff/` に置き、このリポジトリには配信用の縮小版だけを置きます。

## 新規アプリの画像候補

- この運用は新規アプリだけを対象にします。既存の `daily-book-app`、`akebono-app`、`gohan-garapon-app`、`asobi-teian-app`、`matomemo-app` は、現在の登録素材を使い続けます。
- 1アプリ10投稿につき、画像付き投稿は異なる画像6枚で固定します。画像なし投稿は最大4本、画像の使い回しはしません。
- 候補画像は各アプリのprivateリポジトリ内 `docs/apple-app-production/x-post-candidates/` に保管します。候補の開発段階、画面名、状態、撮影元コミット、説明、X公開可否、画面内文字、Before-After関係を記録します。
- Before-After合成画像を使う場合は、画面2枚を左右に並べるだけにし、装飾や文字入れはしません。
- Codexは10投稿の骨子（テーマと要点）と画像候補までを作成し、投稿本文はX投稿担当のClaudeが作成します。
- 必須条件と公開安全性をCodexが確認し、すべて満たした場合だけ6枚をこのpublicリポジトリへ自動pushします。Vaultには画像バイナリを置かず、push後のraw URLを含む `画像一覧.md` だけを更新します。
